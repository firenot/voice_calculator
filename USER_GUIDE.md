#  Руководство пользователя: Голосовой калькулятор (Voice Calculator)

**Версия:** 1.0  
**Поддерживаемые платформы:** Android, Windows


##  1. Общее описание

**Voice Calculator** — это приложение для выполнения математических расчетов с помощью **голосового ввода на русском языке**. В приложении отсутствует стандартная кнопочная клавиатура: все команды подаются голосом.

### Главные особенности:
* **Автономность:** Распознавание речи происходит непосредственно на вашем устройстве (Android или ПК). Ваши голосовые данные не передаются на сторонние серверы и не требуют подключения к интернету.
* **Распознавание естественной речи:** Вы можете произносить числа и математические операции так, как вам удобно (например, «двадцать пять плюс сорок», «к трём прибавить семь», «восемь увеличить в шесть раз»).
* **Сохранение истории:** Все посчитанные выражения сохраняются в списке истории для удобного просмотра прошлых результатов.


##  2. Установка и запуск

###  На смартфонах и планшетах (Android)
1. Установите приложение из `.apk` файла.
2. Откройте приложение.
3. **Важно:** При первом запуске разрешите приложение использовать **микрофон**. Без этого разрешения голосовой ввод работать не будет.

###  На компьютере (Windows)
1. Распакуйте архив с приложением в удобную папку.
2. Запустите файл `voice_calculator.exe`.
3. Убедитесь, что к компьютеру подключен и настроен микрофон. При запросе системы разрешите приложению доступ к устройствам записи звука.


##  3. Как пользоваться калькулятором

### 3.1. Запись голосовой команды
1. Нажмите на большую кнопку с иконкой **Микрофона**  на экране.
2. Четко произнесите математическое выражение на русском языке.
3. После завершения фразы приложение обработает вашу речь, отобразит распознанный текст и автоматически посчитает результат.


### 3.2. Поддерживаемые голосовые команды и примеры

Приложение распознает числительные, служебные слова и основные математические операции.

####  Базовые арифметические операции:
* **Сложение (`+`):**
    * *Фраза:* `«двадцать пять плюс четырнадцать»`
    * *Результат:* `25 + 14 = 39`
    * *Полный список распозноваемых слов:* `«плюс, прибавить, сложить, и, добавить, сумма, увеличить»`
* **Вычитание (`-`):**
    * *Фраза:* `«сто минус сорок пять»`
    * *Результат:* `100 - 45 = 55`
    * *Полный список распозноваемых слов:* `«минус, вычесть, отнять, без, разность, уменшить»`
* **Умножение (`*`):**
    * *Фраза:* `«семь умножить на восемь»`
    * *Результат:* `7 * 8 = 56`
    * *Полный список распозноваемых слов:* `«увеличь в, умножить на, умножить, на, помножить, произведение»`
* **Деление (`/`):**
    * *Фраза:* `«сорок восемь разделить на шесть»`
    * *Результат:* `48 / 6 = 8`
    * *Полный список распозноваемых слов:* `«разделить на, разделить, делить, поделить, частное»`

  

##  4. Работа с историей вычислений

1. В верхнем правом углу экрана расположен список **Истории**.
2. Каждая успешно выполненная голосовая команда автоматически добавляется в этот список вместе с результатом.
3. Вы можете просмотреть прошлые вычисления в любой момент во время работы с приложением.



## 🛠 5. Устранение неполадок

| Проблема | Причина | Способ решения |
| :--- | :--- | :--- |
| **Приложение не реагирует на кнопку микрофона** | Не выданы права на доступ к микрофону | Перейдите в настройки устройства ➔ «Приложения» ➔ «Voice Calculator» ➔ «Разрешения» и включите доступ к Микрофону. |
| **Неверное распознавание слов** | Фоновый шум или нечеткая речь | Говорите с обычной скоростью, избегая громких фоновых шумов. Убедитесь, что микрофон не закрыт пальцем / чехлом. |
| **Ошибка вычисления ("Не удалось распознать выражение")** | Сложная или некорректная формулировка | Попробуйте сформулировать выражение проще (например, сказать `«двадцать плюс десять»` вместо более сложной конструкции). |
| **На Windows нет звукового отклика / распознавания** | Выбран не тот микрофон по умолчанию | Проверьте настройки звука Windows и убедитесь, что нужный микрофон выбран как «Устройство ввода по умолчанию». |
